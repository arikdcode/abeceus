# System Name Candidates

Potential names for the game system (not the world — Abeceus is the setting).

---

## Current Favorites

### Crucible
A container in which things are subjected to extreme heat and pressure. Transforms what's put into it. Reveals what something is actually made of. Fits the design philosophy: combat as a test that forges and changes characters, burning away everything that isn't essential. Clean, one word, evocative.

*"We're playing Crucible tonight."*

---

## Other Candidates

### Substrate
The underlying layer everything else is built on. Fitting for a VTT-native system where the engine *is* the game. Also carries a biological/chemical connotation — the substance an enzyme acts on, the foundation a culture grows from.

### Caliber
Both a weapons measurement and a measure of a person's quality. Double meaning that fits a system about both ballistic reality and character under pressure.
